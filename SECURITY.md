# Security and responsible use

By Jason Stys. This is a simulator-only portfolio lab, not operational flight software.

Report vulnerabilities privately through GitHub's private vulnerability reporting
when available. Do not post tokens, real flight records, private reports, passwords
or exploit payloads against real aircraft in public issues. Public issues may request
a non-sensitive private reporting route, without disclosing the vulnerability itself.

Only the current source-pinned prototype is maintained. There is no safety,
airworthiness, DoD/FAA certification, secure-host attestation or professional audit
claim. Use only app-owned software simulations on an isolated authorized host.
Never redirect ports, attach radios, bridge a real aircraft or expose the preview
server publicly. See [threat model](docs/SECURITY.md), [limits](README.md#limits-that-matter)
and [operations](docs/OPERATIONS.md).
